# Findings of `lake exe check-decls` that exist today.
#
# One finding per line: its kind, then the declaration it is reported at.
# A finding not listed here fails the check.
# A line that no longer matches a finding fails the check too, so this file is
# always the exact list of findings that exist.
#
# Upstream EthLib keeps this list empty and never adds an entry. This fork
# (EmbeddedEthLib) lists exactly the substitutions it makes on purpose, and
# nothing else may be added: every `csimp` entry is a theorem `f = fFast` that the
# kernel checked, and EMBEDDED.md names the module that proves it. No `extern`,
# `implemented_by`, axiom, `partial` or `unsafe` finding may ever be listed.
# SOUNDNESS.md, section B5, explains what such an entry does and does not trust.

# The fast forms read bytes in place with `ByteArray.uget`, whose `USize` index
# reaches `System.Platform.getNumBits`, the platform word size, which is opaque.
# The kernel cannot evaluate these four definitions by unfolding. Nothing in this
# repository asks it to: their proofs rewrite them, and the specification they
# stand in for stays fully reducible. Lean core's `USize` operations reach
# `getNumBits` the same way.
reaches-opaque EthLib.Cryptography.Hash.Sha256.Zsf.wordU
reaches-opaque EthLib.Cryptography.Hash.Keccak.Fast.rdU
reaches-opaque EthLib.Cryptography.Hash.Keccak.Fast.rdb
